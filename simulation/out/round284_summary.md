## 一、为什么要有这一步
#283 发现「时间推进的死亡点」随路径、测程、分辨率而变（滞后带）。本轮不再用演化判存在，直接解定常方程。

## 二、方法
方程（Fourier）：`F(u)=mask*(FFT(PUMP+i|u|²u)+linop(β3)·uhat)`。
行波 ansatz：`u(x,t)=U(x-c t)` ⇒ 定常方程 `F(U)+c·(i k U)=0`。
未知量：活跃模实/虚部 + 漂移速度 c（列包含 DC 模，泵浦平衡由 DC 方程承担）。
Jacobian：逐列中心差分（步长 `1e-7*max(1,|x_j|)`，固定步长会因幅值~60 而下溢）；Gauss–Newton + 回溯线搜索，不设相位规范（平移零模由 lstsq 最小范数步吸收）。

## 四、物理裁决
1. **A 支（0.4849 态）是真实的行波定常解**，不是慢演化暂态；N128 与 N160 的 ext 与 c 完全一致 ⇒ 解支跨分辨率连续，此前的“跨 N 差 3pp”是**初值盆效应**，不是解本身差异。
2. **β3≈0.1965–0.1975 发生 Hopf 失稳**：复本征值 Re 由 0 变正（0.20 时 +1.05e-2，Im=4.85，周期 2π/4.85≈1.30）。这解释了时间推进里看到的“0.1995/0.2000 崩塌”——态离开了不稳定的解支，而不是解消失。
3. **解支本身继续存在到 β3≈0.24**（ext 0.4752），0.25 处 Newton 失败且 svmin 崩塌 ⇒ **上折叠（存在边界）在 0.24–0.25**，不是 0.20。
4. **崩溃后落点 0.4133 是另一条真解支**：0.1992 处残差 3e-13、c=0.6364、Re λ≈5e-7（仅剩平移零模），与 A 同 β3 共存 ⇒ 多稳态=**多解支共存**。

## 五、方法学教训
- 不要把幅值 ~N 的 FFT 系数直接拿固定差分步长算 Jacobian：需逐列按幅值缩放。
- 不要加“相位规范”来固定平移：相位规范与平移零模会打架，让残差卡在规范值上不降；直接 lstsq 吸收零模更稳。
- 先扫 c 给初值（F+c·∂x 残差在真实 c 处降两个量级），否则 Newton 从 c=0 出发走错支。
- 判定顺序：先牛顿找解（存在性），再看 Jacobian 谱（稳定性），最后才看时间演化（动力学/落点）；三步不能混。
