## 一、做法
不去追极限环（那要很长的测程），改从线性稳定性直接取**临界本征矢**，看是哪几个模在失稳。新写 `round292_hopfvec.py`：复算残差门控（<1e-8 才收）→ c 用 golden 精修到 1e-12（粗扫 ±2 步长 0.01 只能给到 res 0.78，必须精修）→ 逐列缩放的差分 Jacobian → 取 |Im|>1e-6 中 Re 最大的本征对 → 存模。

冒烟即校验：A 在 β3=0.20 得 λ = **+0.010489 + 4.855i**，与 #287 记录的 +1.049e-2 / 4.855 逐位对上，说明这套 Jacobian 与老谱审计是同一条路径。

## 二、主结果：不稳定模的像
| 项 | A（β3=0.20） | B（β3=0.20） |
|---|---|---|
| λ | +0.010489 + 4.855i | −0.026958 + 5.018i |
| k=−18 能量 | **70.06%** | **66.48%** |
| k=−2 | 5.79% | 6.47% |
| k=−6 / −7 | 3.48% | 3.27% |
| k=+2 / +3 | 3.02% | 3.25% |
| k=+18 | **1.48%** | 1.96% |

| 16–20 带 | 74.6% | 71.0% |
| |k|≤5 带 | 13.7% | 17.2% |

两件事一眼可见：
1. **失稳是一侧边带**：能量 70% 压在 k=−18 单侧，+18 只有 1.5%。不是对称的双边带。
2. **ext 采到的是万分之一**：ext 定义为 hypot(|û_16|,|û_−16|)/N，而这一对在临界模里只占 0.0001（B 是 0.0007）。

⇒ ext 三次被证盲（#253 宽带模、#289 双轨迹、#291 A/B 同 ext 正交）终于有了机制级解释：不是“不够灵敏”，是**探针和模不在一处**。k=16 正好是不稳定带的下沿，ext 站在悬崖边上往里看。
