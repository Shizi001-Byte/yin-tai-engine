# 四阶外带 MI 饱和态的最大 Lyapunov 指数：分辨率收敛与空间平移中性模

- 轮次：#234（阳期深度轮，2026-10-17）
- 作者：寂雷（纯阴 / 电磁数理方向）
- 任务：P1 广义 LLE 扩展 · 第三步「严格饱和 Lyapunov 指数」的分辨率收敛核验
- 复现脚本：`simulation/round231_P1_0.py`（严格 λ1 框架，自包含）、`simulation/round234_P1_0.py`（分辨率收敛，import 复用 round231）
- 证据分级：P2 收敛数值（N=96↔N=128 配对），叠加解析论证（平移零模）

## 一、问题

四阶色散（β₄=1）广义 LLE 在连续波（CW）之上对 q=4.8 外带存在线性调制不稳定（MI），
线性增长率 λ_lin=+0.998（#213 解析闭形式已验证）。这条线性 MI 通道在非线性饱和后
究竟走向**稳定锁模**还是**持续时空混沌**，必须由严格饱和的最大 Lyapunov 指数 λ₁
（长 warmup、warmup 后重置切向量、分段 Benettin 重正化）回答，而非线性 MI 瞬态增长率
或短测程 FTLE。

参数：Δ=3, S=2, CW 强度 I=2, D=1, β₄=1（CW 关系 S²=I[1+(Δ−I)²]=4）；
域 L=20π/3（dq=0.3），q=4.8 对应 Fourier 指标 j=16。

## 二、方法

- 伪谱（2/3 dealiasing）+ 切向量 Benettin，RK4 时间积分；
- warmup=100 后重置切向量（排除 MI 线性瞬态污染），measure=100，每 t=1 重正化；
- 三分辨率 N=64/96/128 **统一时间步 dt=0.002**、**统一物理初值**（公共低 q 模
  j=1..20，即 q=0.3..6.0 写入完全相同的复系数，q>6 置零，再叠加同一 q=4.8 余弦扰动；
  硬断言三个 N 的初值在公共模上为同一物理场）；
- 判定：后半程 λ₁ 置信区间 + 终态 RHS 残差 + 外带振幅 CV + 相邻 N 配对差值 +
  q>6 高模能量占比；
- 对 λ₁≈0 追加三重独立核验：Benettin 重正化、不重正化扰动幅度平台、冻结 Jacobian
  零模向量。

## 三、结果

### 1. N=96 → N=128 完美收敛

| N | λ₁(后半程) | 终态残差 | 主导 q | q=4.8 外带占比 | 振幅 CV | q>6 占比 |
|---|---|---|---|---|---|---|
| 64 | −0.0527 | 4e-9 | 0.9 | 0.1042 | 3e-15 | 4e-4 |
| 96 | ≈0 | 3e-7 | 0.9 | 0.1008 | 4e-12 | 5.8e-4 |
| 128 | ≈0 | 7e-12 | 0.9 | 0.1008 | 5e-15 | 5.8e-4 |

N=96↔N=128 配对：λ₁ 差=0、外带占比差=4.9e-5、低 q 复系数最大差=1.9e-4、
归一化总功率 1.2324 vs 1.2325、q>6 高模占比 5.82e-4 vs 5.83e-4（已收敛的小尾，非截断）。
**N=64 的 λ₁=−0.0527 是粗分辨率离散误差**，真实饱和 λ₁ 随分辨率收敛到 0。

### 2. 饱和态：定态锁模梳子

终态 RHS 残差 7e-12、外带振幅 CV=5e-15（机器精度定态）。功率谱（N=96/128 一致）：
q=0（CW）约 36%，低 q 分量主导（q=±0.9 各 11.3%，q=±1.5 各 4.9%，q=±2.4 各 3%），
q=±4.8 弱外带合计约 10%。

### 3. λ₁=0 是空间平移 Goldstone 中性模，非混沌

分段 Benettin 增长率：早期负（t=1 约 −0.7，随机切向量中的横截模衰减），t≥21 起
严格为 0；不重正化扰动衰减到一个**非零恒定平台**（初始 RMS 的 0.93，t=20–120 八位数
不变），排除“衰减到数值零”的假零。

- 冻结 Jacobian 作用于空间平移向量 v=∂ₓu*（Fourier 系数 i·q·u*）：
  ‖J(∂ₓu*)‖/‖∂ₓu*‖ ≈ 1.2e-6（平移后状态的定态残差仍为 7e-12）；
- 全局相位向量 v=i·u* 不是零模：‖J(iu*)‖/‖iu*‖ ≈ 1.8（含固定驱动 PUMP 的受迫耗散
  系统显式破缺 U(1) 相位对称，相位被泵钉住）；
- 但空间均匀泵浦保留连续 x 平移对称性，给出严格的平移零模。

**结论：饱和态是横截方向渐近稳定、沿平移轨道中性的定态锁模族（stability modulo
translation），λ₁=0（中性）而非 λ₁>0，四阶外带 MI 不通向持续时空混沌。**

## 四、修正链（短积分 → 收敛）

1. #219 短测程 FTLE 0.5–0.75：未 warmup 重置切向量，混入线性 MI 瞬态；
2. #231 N=64 broadband 给 λ=−0.046：粗分辨率 + 短 warmup + 不同 N 初值不统一；
3. #231 N=64 纯对称初值给 λ=+1.44：一个物理不可达的不稳定精确驻波分支（外带约 50%，
   1e-10 宽带微扰即破坏）；
4. #234 分辨率收敛 + 统一物理初值：λ₁=0（空间平移中性模），饱和态为弱外带定态锁模。

## 五、方法学坑（可复用）

1. **分辨率可反转定性符号**：N=64 给显著负、N=96/128 收敛给零，连“负还是零”都会变；
   多分辨率必须用统一物理初值（公共低 q 模同物理场 + 跨 N 硬断言），否则不同 N 的
   初值本就不同，不构成收敛研究。
2. **q⁴ 时间步约束**：四阶色散线性算子虚部 ~ q⁴，RK4 虚轴稳定要求
   max_z = dt·max|linop.imag| < 2.8，随 N 急剧增大（N=96@dt=0.0025 为 1.11，
   N=128@dt=0.0025 为 3.0 会断言失败）；分辨率扫描必须让 dt 随 N 减小。
3. **冻结 Jacobian 实矩阵的分块提取陷阱**：用 Re/Im(Fourier) 手写实线性矩阵分块时
   极易出错（某次实现给出虚假的 +76 正本征值、86 个正模，与机器精度定态矛盾；
   但直接调用切线性化算子做实线性叠加的误差仅 9e-13）。本征值结论必须用物理时间
   积分（不重正化扰动平台 / Benettin）交叉验证；矩阵 eig 仅作辅助，且须先通过
   “矩阵作用 vs 算子作用”的 sanity 校验。
4. **λ=0 中性模的辨识**：受迫系统（含固定 PUMP）破缺相位对称但常保留平移对称，
   零模是 v=∂ₓu* 而非 iu*；判据是平移 u* 后定态残差仍为机器精度，且 J(∂ₓu*)≈0。
   λ=0 配非零扰动平台才是中性模；数值假零会让扰动衰减到机器零。
