# β4 四阶反常色散外带 MI 的非线性动力学验证（#219，VERIFIED）

承接 notes/glle-beta3-beta4-mi-spectrum.md（#213 线性谱）。

## 一句话
#213 线性理论预测正四阶反常色散 β4 在高 q 打开第二（外）MI 带；#219 用 Fourier 伪谱 RK4 + 切向量 Benettin 重正化做非线性动力学，确认该外带在线性→非线性间确实承接能量、主导模式锁定 q=4.8；β4=0 无此现象。

## 模型/参数（与 #213 锁定一致）
GLLE Δ=3, S=2, CW 强度 I=2, D=1；X4=2I−Δ−Dq²+β4 q⁴/24，γ3=β3 q³/6。

非线性方程（CW 旋转坐标）：

```
dA/dt = C − A + i(|A|²−Δ)A + [iD∂₂ − β3/6 ∂₃ + iβ4/24 ∂₄]A
C = √I (1 + i(Δ−I))   # 使 A0=√I 为精确稳态
```

数值：L=10π, dq=0.2, N=160, dt=0.0025, RK4, 2/3 dealiasing；切向量 Benettin 重正化每 0.025 时间单位；warmup=20, measure=40。

## 自校验（机器精度）
- 新伪谱 RHS 的 q 边带投影矩阵 vs #213 已验证 tangent_matrix（多组 β3/β4/q）：最大误差 **2.67e-15**。
- 精确 CW 初态在 RK4 下不动：误差 **3.0e-17**。
- q=3 稳定边带小扰动 t=2 衰减比 0.1341 vs 理论 e^-2=0.1353（差 0.9%）。

## 解析独立复算（Wolfram）
- β4=1, q=4.8：X4=0.0784，λ1=−1+√(4−X4²)=**0.9985**（强不稳定，甚至高于主带 q=0 最大 −1+√3=0.732）。
- β4=1, q=4.6：λ=0.318（外带内）；q=5.0：λ=−1+0.41i（实部−1 稳定）→ 外带边界 [4.567,4.971] 精确。
- β4=0, q=4.8：X4=−22.04，稳定（纯虚根区）。

## 非线性扫描结果（12 case：β3∈{−0.3,0,0.3} × β4∈{0,1} × 初值{broadband,outer}）
外带功率 = q∈[4.567,4.971] 终态非零空间功率占比：

| β3 | β4 | 初值 | 外带功率 | 主导 q | 终态 |
|---|---|---|---|---|---|
| 0 | 0 | broadband | 0.001 | 1.00 | stationary_modulated |
| 0 | 0 | outer | 0.000 | 1.40 | dynamic（主带 MI 驱动，q=4.8 衰减）|
| 0 | 1 | broadband | **0.310** | **4.80** | dynamic |
| 0 | 1 | outer | **0.397** | **4.80** | dynamic |
| ±0.3 | 0 | * | ≤0.002 | 主带 1.0–1.2 | — |
| ±0.3 | 1 | * | 0.028–0.101 | 随 β3 变 | dynamic |

**结论**：β4=1 时能量注入外带并锁定主导模式 q≈4.8；β4=0 外带功率≈0。线性外带 MI → 非线性通道闭环成立。
