## 一、问题

#234 已证明四阶外带 MI 饱和后是空间平移中性的**定态锁模族**（λ₁=0、非混沌）。
三阶色散 β3（奇阶）在线性边带矩阵里引入**虚频** iβ3q³/6，线性理论据此预测边带是
**行波**（相速度 v=−β3q²/6）。两个待回答的问题：

1. β3=±0.3 的饱和非线性态究竟是反向传播的刚性行波，还是仍然空间静止？
2. 能否用一种独立于 Benettin 的方法，严格检验它是否混沌？

## 二、方法：反射共轭判据

复场空间反射 R：u(x)→u(−x)，Fourier 系数 (Rû)_q = û_{−q}（反射**不**取共轭）。

β3 是奇阶（q³ 奇），β4/Δ/D 是偶阶（q²、q⁴ 偶），故

```
R·L(β3)·R⁻¹ = L(−β3)     ⇔     linop(−β3)(q) = linop(β3)(−q)
```

常数 PUMP（q=0）与非线性项 i|u|²u 在反射下均对易。于是确定性动力学给出**精确的轨迹共轭**：

```
若 (β3, u0) 演化为 u₊(t)，则 (−β3, R·u0) 演化为 u₋(t) = R·u₊(t)。
```

这是一个廉价而严格的**混沌影子检测**：两条本该机器精度重合的共轭轨迹，若反射误差
从 ~1e-13 指数放大到 O(1)，即正 Lyapunov 指数的独立证据；若始终保持很小，则非混沌。

机器精度自检（仅 dealiasing 活跃模式，85 个）：

| 检验 | 误差 |
|---|---|
| linop 反射恒等式 | 1.14e-13 |
| state_rhs 反射 | 2.58e-12 |
| tangent_rhs 反射 | 3.21e-12 |

**Nyquist 陷阱（方法学坑）**：Fourier 网格 Nyquist 点 j=N/2 自配对（q≡−q），奇阶 β3
项反射后要求 q³ 变号却映到自身，恒等式在该点天然不成立，残差 = 2|β3||q|³/6
（N=128，q=19.2，=707.8）。该点已被 2/3 dealiasing 的 mask 屏蔽、从不参与动力学，
反射自检必须只在 mask=1 的活跃模式上比较，否则全数组比较会误报 707.8。

### 3.2 λ₁→0（非混沌），反射误差不放大

| 测程 | λ₂ₙd（后半程） | λ（最后20段） | 终态反射相对误差 |
|---|---|---|---|
| warmup100 + measure100（总200） | 0.064 ± 0.040 | — | 7.94e-9 |
| warmup100 + measure200（总300） | 0.026 ± 0.026 | −0.019 | 1.07e-7 |

- λ 随测程向 0 收敛（0.064→0.026→末段转负），measure=100 的 0.064 是**未衰减完的弱瞬态**，
  不是持续正率；β3± 配对 λ 完全一致（差 ~3e-4）。
- 反射误差从 1e-13 起步，300 时间单位后仅 1.07e-7，隐含弱率 ≈ ln(1e-7/1e-13)/300 ≈ 0.026
  且随时间衰减，与 Benettin 的 λ₂ₙd 独立互证。若真有正 λ≈0.5，误差应放大 e^{0.5×300}~1e65
  到 O(1)；实测远未达到。**两条独立证据一致指向非混沌、中性。**

### 3.3 核心物理：饱和锁模梳子被"空间冻结"，不是刚性行波

从饱和终态继续积分，用 **unwrap 解缠绕 + 逐模线性拟合 φ_q=−qv t**（见 drift_audit）
并以**物理空间相邻帧互相关**交叉验证：

- **主导锁模梳子**（q=0.9/1.5/2.1/2.4/3.0/3.9/±5.4 等 16 个显著模）给出共同速度
  **v≈0**：谱法 β3+ 为 −0.0092±0.0028、β3− 为 +0.0092±0.0028（精确镜像、和≈0），
  物理空间互相关 **v=0**（4 时间单位内图案位移不足一个网格 L/N=0.164）。
- **仅近线性的小振幅残留外带**保留线性漂移：q=4.8（功率 1.5%）实测 v=−1.10，
  与线性预测 −β3q²/6 = −1.15 吻合；这类模相位拟合残差大、未锁入主梳子。

## 四、物理结论与修正

线性理论里 β3 给边带虚频（ω=β3q³/6），看似驱动行波；但**大振幅饱和锁模梳子经
非线性 i|u|²u 的相位锁定与耗散，把空间速度冻结到 v≈0**。只有近似线性、非线性耦合弱的
小振幅残留外带，才保留线性行波速度。

因此 β3=±0.3 的饱和态是**空间近静止、互为反射镜像的锁模梳子**，而非刚性行波；
λ₁→0、非混沌。这与 #234 构成同构教训：

> **线性边带的虚频（行波趋势）与增长率（MI 强度）都不能直接外推到非线性饱和态；
> 饱和后的锁相和耗散会同时冻结"是否放大"和"是否移动"。**

## 五、方法学坑（复现者必读）

1. **反射自检须排除 Nyquist**：只在 mask=1 活跃模式比较 R·L(β3)·R⁻¹ 与 L(−β3)，
   否则 j=N/2 自配对点误报 2|β3||q|³/6（N=128 约 707.8）。
2. **行波速度必须解缠绕**：用 `np.unwrap` 逐模相位 + 线性拟合 φ=−qvt；直接用
   `np.angle` 包裹相位算瞬时速度，在 qvt>π 时高 q 模缠绕，会导致速度 std 爆到 0.6–0.9、
   甚至符号翻转（worker 初版 estimate_drift 的问题）。最可靠是物理空间互相关。
3. **刚性行波判据**：所有显著模 v_q 一致才是刚性行波；若只有个别小振幅模快漂移、
   主梳子 v≈0，那是"冻结锁模 + 近线性残留外带"，不是整体行波。
4. **固定网格定态残差判据对移动态失效**：移动行波在实验室坐标系残差非零（本轮 1.47）
   但并非混沌，需用随动坐标系或互相关判读。
