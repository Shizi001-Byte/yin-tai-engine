# 广义 LLE 三阶/四阶色散对调制不稳定性（MI）的影响 · 局域线性谱

- 轮次：寂雷 #213（阳期深度轮，2026-10-16）
- 任务：engineering/P1 广义 LLE 扩展——三阶/四阶色散
- 状态：**VERIFIED**（数值矩阵 ↔ 解析公式机器精度一致；关键常数 Wolfram 独立复核；可复现脚本已实跑全绿）
- 可复现脚本：引擎 `simulation/round213_P1_0.py`（numpy，纯标准线性代数）

## 1. 模型与参数

广义 Lugiato–Lefever 方程（GLLE，含三阶 β3、四阶 β4 色散），均匀稳态（CW）：

- 参数：Δ=3，S=2，CW 强度 I=2，二阶色散系数 D=1。
- CW 关系：S² = I[1+(Δ−I)²] = 2·(1+1)=4，残差 0（已验证）。
- 对边带对 (u_q, u*_{−q}) 线性化，2×2 切向矩阵：

```
[ −1 + i(X4+γ3) ,    i I          ]
[ −i I           , −1 − i(X4−γ3)  ]
```

其中

```
γ3 = β3 q³ / 6
X4 = 2I − Δ − D q² + β4 q⁴ / 24
```

## 2. 解析本征值

```
λ± = −1 + i γ3 ± sqrt(I² − X4²)
```

- 迹给平均 −1+i γ3；判别式 = 4(I²−X4²)，**不含 γ3**。
- 数值本征值（`np.linalg.eigvals`）与解析公式最大绝对误差 = **3.66e−15**（机器精度）。
- 正 MI（有正实增长）条件：**|X4| < sqrt(I²−1)**。

## 3. 三阶色散 β3：只平移频率，不改变 MI 增益

β3 项给两支本征值加一个**公共虚频移** iβ3 q³/6，不进入实部：

- q=1.5、β4=0、β3∈{−0.3, 0, 0.3} 时，最大实增长率 spread = **3.33e−16**（机器精度）。
- 物理含义：三阶色散只在时间域平移扰动相位，**不增益也不抑制 MI**；其影响只能通过非线性相互作用体现。

## 4. 四阶色散 β4：改变 MI 增益并打开高阶外带

β4 经 X4 改变边带增益与不稳定能带：

| 条件 | 不稳定 q 带（数值扫描） | 解析边界 |
|---|---|---|
| β4=0 | [0, 1.652] | √(1+√3)=1.6529 |
| β4=1 | [0, 1.773] ＋ **[4.567, 4.971]**（外带） | y=q²，\|1−y+y²/24\|=√3 |

对照点（q=1.5，β3=0.2，Wolfram 独立复核）：

| β4 | X4 | λ1 实部 |
|---|---|---|
| −0.2 | −1.2921875 | 0.52652 |
| 0.0 | −1.2500000 | 0.56125 |
| +0.2 | −1.2078125 | 0.59411 |

- 物理含义：**正 β4（四阶反常色散）在高阶 q 区（q≈4.6–5.0）制造第二（外）MI 不稳定带**，即四阶 MI；主带边界随 β4 移动。

## 5. 核验过程（诚实记录：实跑抓到两个 bug）

深度轮产出脚本后，决策层实跑断言，发现并修复：

1. **纯虚根区本征值排序配对翻转（测试 bug，非物理错）**：当 I²−X4²<0，两支本征值实部相同、虚部互为 ±，`sort_complex` 按 (real,imag) 排序时因 ~1e−16 浮点差在实部主键上翻转，逐元素配对错位，假报 worst=16.88；改为集合最优配对（枚举 2 种排列）后误差 1.98e−15。
2. **单点常数笔误**：worker 手填的 β4=−0.2 期望增益 0.52599 有误，正确值 0.52651612（Wolfram `N[-1+Sqrt[4-(-1.2921875)^2]]` 复核）；β4=0/+0.2 两点正确。

修复后脚本全部断言通过。
