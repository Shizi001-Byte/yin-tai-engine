|---|---|---|---|---|
| 0.15 | 16.4 | 11.5 | 16.4 | 11.5 |
| 0.16 | 12.9 | 11.6 | 12.9 | 11.6 |

## 三、超长测程（measure800）判定 β3=0.20：多稳态 VERIFIED

measure 段每 200 单位报告外带振幅 seg_ext（高功率态是否跌落）：

| seed | N128 ext 四段 → q48 终态 | N160 ext 四段 → q48 终态 |
|---|---|---|
| 240 | 0.148/0.147/0.147/0.148 → 2.6% | 0.148/0.147/0.147/0.147 → 2.0% |
| 241 | 0.273/0.281/0.297/**0.339** → 9.3%（仍在增） | 0.276/0.174/0.145/**0.145** → 0.2%（跌落） |
| 237 | 0.355/0.340/0.339/**0.340** → 8.8% | 0.151/0.147/0.147/**0.148** → 4.5%（跌落） |
| 242 | **0.440/0.440/0.440/0.440** → 13.0% | **0.440/0.440/0.440/0.440** → 13.0% |

- **低功率外带抑制态** ext≈0.147 / q48≈2–2.6%：seed240 在 N128、N160 均稳定落入（四段恒定）。
- **高功率锁模态** ext=0.440 / q48=13.0% / λ=0：seed242 在 N128、N160 **完全相同**、四段恒定。
- 同一 seed 240 双N都到低态、同一 seed 242 双N都到高态 → 吸引子由初值选择且**跨分辨率稳定**，不是 #240 那种低分辨率镜像敏感伪影。
- seed241/237 在 N128 暂留中功率态（ext≈0.34），在 N160 继续衰减至低态 → 中功率态更像长寿命亚稳态（分辨率影响收敛速度）。
- 所有终态 λ_last20 均在 −0.014 ~ +0.026（高态=0 锁模），无双N+双seed一致持续正 λ → **多稳态是多个锁模态共存，非混沌**。

## 四、对 #240 的修正

- #240 仅用 seed240：看到“β3 0.15→0.20 外带功率 16.4%→2.8%、非线性相位锁定抑制”。这是**seed240 这一初值的轨迹**（它在 0.20 落低态）。
- 多 seed 长测程揭示真相：**β3=0.20 是高功率锁模态与低功率抑制态共存的多稳态点，“抑制”不是对所有初值同步发生，而是初值依赖的吸引子选择**。#240 的“平滑/陡降抑制曲线”是多稳态盆地沿单一切片的投影。
- 线性实增长率跨 β3 恒定 0.9985（#240 已证），故多稳态/外带抑制仍是**非线性相位锁定与谱能量重分配**，非线性增益改变。
